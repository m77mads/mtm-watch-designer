# MTM Watch Designer

## Instagram skills (`ig-*`)

The account's voice profile lives in this repo at `.claude/instagram/voice.md`.
The `ig-*` skills look for `~/.claude/instagram/voice.md`; if that file is
missing (fresh cloud session), copy the repo one there first:

```bash
mkdir -p ~/.claude/instagram && cp .claude/instagram/voice.md ~/.claude/instagram/voice.md
```

The account's reels are **silent**: no voiceover, no face. Write the on-screen
text cards as the script, in Kuwaiti Arabic, and end with a keyword CTA.
